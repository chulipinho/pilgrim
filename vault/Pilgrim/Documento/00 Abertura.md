# Abertura

> **Pergunta central:** o que este documento é, e por que ele existe?

## Decisão

Este é um **documento conceitual de design** — uma bíblia de decisões, não um manual de regras. Ele existe para pensar o jogo com clareza, registrar por que cada escolha foi feita e deixar visível o que ainda não foi decidido.

Ele é escrito em português, vive no vault, e é feito de notas ligadas. Cada nota responde a uma pergunta.

## Por quê

Um jogo como este — peregrinação, duelo, memória, sobrevivência — corre o risco de virar uma coleção de ideias soltas. O documento existe para impedir que isso aconteça: ele separa o que é **pilar** do que é **consequência**, e o que é **decisão** do que é **possibilidade**.

O formato de perguntas foi escolhido porque obriga cada escolha a nomear o problema que resolve.

## A tensão central

O jogo é sobre uma peregrinação até uma pessoa que se lembra. Tudo o mais — o combate, os perigos, as cidades, os ritos, os boatos — existe para que essa chegada tenha peso.

A pergunta que o jogo faz ao jogador não é "você é bom ou mau?". É:

> **O que você fez, e o que o mundo vai acreditar que você fez?**

## O que mudou em relação ao conceito original

O arquivo [[Pilgrim]] continua sendo a semente. Estas são as mudanças conceituais registradas neste documento:

| Conceito original | Decisão atual |
|---|---|
| Oito caminhos como finais distintos | Oito caminhos como **vereditos** combinados com três finais universais |
| "Sem cura" | Sem cura **durante o duelo**; a condição física recupera entre duelos |
| "Boatos" como categoria única | Separação entre **boatos** (sobre o mundo) e **fama** (sobre o jogador) |
| Peregrinação até um ponto do mapa | Bacia central aberta, com o destino fixo no centro |
| Purificação como um caminho | Purificação como **sistema de rito**, alternativa ao combate |
| Progressão por experiência | Progressão **horizontal**; inimigos ganham habilidade, não atributos |
| Escopo indefinido | Oito regiões iniciais; expansão modular depois |

## O que este documento não é

- Não é um GDD de produção.
- Não é uma lista de tarefas.
- Não é um romance.
- Não é uma promessa de que tudo será construído.
