# Quais são os pilares?

> **Pergunta central:** quais ideias não podem ser traídas, mesmo que tudo o mais mude?

## Decisão

Cinco pilares. Eles são testes: se uma decisão futura violar um deles, a decisão está errada — ou o pilar precisa ser reescrito de forma explícita.

### 1. Justiça

O jogo precisa ser justo. Isso significa:

- **Simetria mecânica:** todo duelista humanoide obedece às mesmas regras do jogador. Vida comparável, mesmas vulnerabilidades, mesmo atordoamento, mesma interrupção.
- **Sem inflação de atributos:** nenhum chefe tem 10.000 de vida enquanto o jogador tem 100.
- **Sem imunidades arbitrárias:** se o jogador pode ser derrubado, o inimigo também pode; se o jogador sofre com o frio, o inimigo também sofre.
- **Sem dano de contato:** encostar não machuca; só ataques machucam.
- **Perigo legível:** o jogador deve poder ver, ouvir ou ouvir falar do perigo antes de morrer por ele.
- **Sem trapaça invisível:** a IA não lê comandos nem ganha vantagens escondidas.

### 2. Leitura e comprometimento

O combate é vencido por leitura, não por execução de combos infinitos.

- Todo ataque compromete.
- A defesa é um triângulo de guarda, aparo e passo.
- O dano é alto; o duelo é curto.
- Não há cura durante o duelo.
- A dificuldade vem da habilidade do oponente, não dos números dele.

### 3. A estrada é a build

Não há níveis. O jogador cresce horizontalmente:

- estilos (armas),
- técnicas de proveniência,
- equipamento,
- marcas de adaptação,
- conhecimento,
- relíquias,
- fama.

Um jogador habilidoso pode sobreviver em qualquer lugar; um jogador preparado prospera.

### 4. A memória é a aposta

O jogo distingue **feitos** (o que aconteceu) de **fama** (o que se acredita).

- As regiões têm versões diferentes do jogador.
- A fama se espalha, pode ser falsa, pode ser reparada a um custo.
- O final é um registro, não uma recompensa.
- Matar testemunhas muda o que o mundo sabe — e o que ele pode lembrar.

### 5. O rito é uma alternativa real

A purificação não é um detalhe de história. É um caminho de jogo:

- Cada região tem uma ferida.
- O rito é montado a partir de conhecimento e ingredientes locais.
- Purificar uma pessoa significa limpar a fonte que a aflige, não vencê-la em combate.
- O jogo nunca confirma se o sagrado é real; mostra os efeitos.

## O que os pilares proíbem

- Chefes com atributos inflados.
- Imunidades que o jogador não pode obter.
- Progressão por nível.
- Combate de hordas.
- Finais que ignoram o que o jogador fez.
- Purificação como cutscene.

## O que isso custa

- Exige IA e animação de alta qualidade: a simetria expõe qualquer desonestidade.
- Exige conteúdo autoral: não dá para gerar fama, ritos e duelos proceduralmente sem perder o tom.
- Exige disciplina de escopo: oito regiões já é muito.
